## Bugs found and fixed during testing

1. **Chunk header size**: implementation initially treated the header as 12
   bytes instead of 10 (2+4+2+2), corrupting every reassembled message. Fixed in
   `proto::CHUNK_HEADER`; docs corrected.
2. **Pointer mapping tolerance**: normalized → pixel → absolute quantization on
   a 1920-wide monitor is ~34 absolute units per pixel; mapping now rounds and
   tests use a realistic tolerance.
3. **egui 0.37 API**: new `App::ui`/`App::logic` split and `Panel::top` API
   adopted.
4. **Non-blocking listener inheritance**: accepted sockets are explicitly set
   back to blocking before the handshake.

## Hardening applied after the first test pass

- bincode decode/serialize calls are bounded to `MAX_LOGICAL + 4 KiB`, so a
  tiny malicious body cannot request an enormous allocation.
- Injecting text is capped at 4096 UTF-16 units and sent in 32-unit batches;
  wheel deltas are clamped to ±20 steps. Both prevent host-side memory/input
  abuse from a malicious viewer.
- The host applies a 10 s timeout to the post-handshake `Hello`; the viewer
  applies 15 s/180 s authorization timeouts. A peer can no longer hold a
  listener or viewer thread forever.
- `Stop listening` now shuts down an in-progress handshake socket, so the port
  is released promptly.
- Capture/encoder/writer failures shut down the session socket instead of
  leaving a half-dead reader thread.
- The viewer no longer maps egui's `command` modifier to the Windows key
  (on Windows it aliases Ctrl) and skips text injection while Ctrl/Alt/Command
  is held.
- The host window title changes to `DeskBeam - SESSION ACTIVE`; the host modal
  clears if the authorization prompt times out or the viewer leaves.
- The non-functional monitor dropdown was replaced by a truthful primary-
  monitor label (selection is M4).
- Cancelling the viewer during DNS/connect/handshake now aborts the background
  attempt instead of leaving an orphan session.
- Empty libvpx output (possible under realtime rate control) is skipped instead
  of being treated as a fatal encoder error.
- The 64-byte handshake label limit is enforced, and CLI flags reject missing
  values.
- Release self-test logging no longer depends on a console handle (a Windows
  GUI-subsystem process can have an invalid stdout; `println!` would panic).
  Results are written to `deskbeam-selftest.txt` and the exit code is reliable.
